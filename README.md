Entry for the [make.fun bounty "Notes From a Passive-Aggressive Fridge"](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

`main.ts` writes one funny passive-aggressive note from a smart fridge to its
owner at `/output/entry.txt`, deterministically (two runs produce byte-identical
output). The note is a single line, 87 characters, within the 1–200 character gate.
